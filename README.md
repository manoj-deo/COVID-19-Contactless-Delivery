# 🧠 Covid-19 Contactless Delivery System

An **IoT-based smart delivery box** designed to enable **contactless parcel exchange** between customers and delivery personnel.  
Built with **Raspberry Pi 4**, **Arduino UNO**, **AI-based Face Recognition**, **RFID authentication**, **IoT Web Control**, and **GPS-GSM tracking**, it ensures **safe, automated, and secure delivery** in a post-Covid world.
